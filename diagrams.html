📝 Descrição de Feature — Realizar Pagamento

Caso de Uso: Realizar Pagamento

Atores Envolvidos: Cliente, Sistema Raízes do Nordeste, Sistema de Pagamento Externo

Pré-condições:
• Cliente autenticado no sistema
• Carrinho com ao menos 1 item
• Unidade selecionada e operacional

Fluxo Principal:
1. Cliente acessa o carrinho e clica em "Finalizar Pedido"
2. Sistema verifica autenticação (redireciona para login se necessário)
3. Sistema exibe as formas de pagamento disponíveis (PIX, Cartão, Dinheiro)
4. Cliente seleciona o método e confirma
5. Sistema envia requisição ao serviço de pagamento externo
6. Serviço externo processa e retorna: aprovado ou negado
7a. (Aprovado) Sistema registra o pedido, credita pontos de fidelidade e redireciona para a tela de acompanhamento
7b. (Negado) Sistema exibe mensagem de erro e oferece opção de tentar novamente ou voltar ao carrinho

Regras de Negócio:
• O sistema Raízes do Nordeste não processa dados financeiros — apenas solicita e aguarda confirmação
• Pontos de fidelidade só são creditados após confirmação de pagamento
• Em caso de falha de comunicação com o serviço externo, o pedido permanece em estado "pendente" e o usuário é notificado

Pós-condições:
• Pedido registrado no sistema com número único
• Resultado do pagamento armazenado para auditoria
• Cozinha notificada (em caso de aprovação)
• Pontos de fidelidade atualizados na conta do cliente
